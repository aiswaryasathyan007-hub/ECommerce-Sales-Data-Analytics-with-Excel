E-Commerce Sales Data Analytics with Excel

Project Overview

This project focuses on cleaning, analyzing, and visualizing e-commerce sales data using Microsoft Excel.

Objectives

Clean and prepare the dataset.

Identify and handle duplicate and missing values.

Apply Excel formulas for data analysis.

Use lookup functions to connect related tables.

Create PivotTables and charts.

Build an interactive sales dashboard.

Identify useful business insights.
